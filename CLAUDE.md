# UGC Brainstorming

Web application for Indonesian content creators to brainstorm UGC soft-selling ideas.

## Tech Stack
- React 18 + Vite + Tailwind CSS
- Vercel Serverless Functions
- Supabase PostgreSQL
- OpenRouter API (oc/minimax-m2.5-free)
